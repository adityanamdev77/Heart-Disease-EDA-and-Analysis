
# ❤️ Heart Disease EDA and Analysis

## 📌 Overview
This project focuses on Exploratory Data Analysis (EDA) of a heart disease dataset using Python. It explores health-related features, identifies patterns, and visualizes relationships between variables to better understand the data.

## 🎯 Objectives
- Understand the dataset structure and features.
- Perform data cleaning and preprocessing.
- Identify missing values and duplicate records.
- Analyze statistical summaries and feature distributions.
- Explore relationships and correlations between variables.
- Create visualizations to discover useful insights.

## 🛠️ Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/adityanamdev77/Heart-Disease-EDA-and-Analysis.git
```

### 2. Navigate to the project directory
```bash
cd Heart-Disease-EDA-and-Analysis
```

### 3. Install dependencies
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

### 4. Launch Jupyter Notebook
```bash
jupyter notebook
```

Open `model2.ipynb` to explore the analysis.

## 📈 Key Learnings
- Working with tabular health-related data.
- Using Pandas and NumPy for data analysis.
- Creating visualizations with Matplotlib and Seaborn.
- Understanding feature distributions and correlations.
- Developing practical EDA skills for Data Science and Machine Learning.
